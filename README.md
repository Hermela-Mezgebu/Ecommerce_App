Flutter E-Commerce App

A fully functional e-commerce mobile application developed with Flutter using Riverpod for state management and a clean, maintainable architecture. The app consumes data from the Fake Store API and demonstrates real-world mobile development practices such as API integration, local storage, error handling, responsive UI, and structured project organization.

Features

User authentication using Fake Store API

Browse all products

Product details page

Browse products by category

Search products by title

Shopping cart with quantity management

Persistent cart using local storage

User profile page

Loading, empty, and error states

Responsive UI for different screen sizes

Tech Stack

Flutter

Riverpod

Dio

SharedPreferences

Clean Architecture

Project Structure

lib/
├── core/
├── data/
├── presentation/
└── main.dart

This project was built as part of a Flutter development challenge to demonstrate clean code, state management, API handling, and scalable mobile app architecture.
